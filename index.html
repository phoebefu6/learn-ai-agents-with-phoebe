Learn AI Agents with Phoebe

Two tracks into the loop behind every AI agent

An agent is an LLM in a loop with tools, directing its own next step - and everything that makes one reliable comes down to four levers: tools, memory, planning, guardrails. A leader track teaches you to judge, scope, and govern agents without touching code. A builder track takes you from reading a live agent trace to assembling the Daybreak Ops Agent - tools, workflow patterns, memory, planning, multi-agent, guardrails, evals - on the same coffee-brand MCP server built in the MCP course. Every builder page has a live agent to run, break, and fix in your browser.
